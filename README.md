# 🚀 DataBridge

## ✨ Description
**DataBridge** est une application web qui permet de valider et convertir vos fichiers XML et DTD facilement et rapidement.

## 🛠 Fonctionnalités

### 🛡 Validation XML
- Vérifie que votre XML est conforme à une **DTD** ou à un **XSD**.

### 🔄 Conversion XML → JSON
- Transforme votre fichier XML en JSON structuré.

### 📝 Conversion DTD → XSD
- Génère automatiquement un schéma XML (XSD) à partir d’une DTD.


## ⚙️ Installation avec Poetry

On utilise **Poetry** pour gérer les dépendances et l’environnement virtuel.  

1. **Cloner le projet** :  
```bash
git clone https://github.com/majda2001/DataBridge.git
cd DataBridge
```

2. **Installer les dépendances** :
```bash
poetry install
```

3. **Lancer le serveur Django** :
```bash
poetry run python manage.py runserver
```

1. **Ouvrir dans le navigateur** :
```bash
http://127.0.0.1:8000/
```
